# Banana IDE Frontend

This project is a simple Integrated Development Environment (IDE) for the "banana" programming language. It allows users to write, run, and view the output of their banana code in a user-friendly interface.

## Project Structure

```
banana-ide-frontend
├── public
│   └── index.html          # Main HTML file for the React application
├── src
│   ├── components
│   │   ├── CodeEditor.jsx  # Component for writing banana code
│   │   ├── Console.jsx      # Component for displaying output
│   │   └── RunButton.jsx    # Component for executing the code
│   ├── App.jsx             # Main application component
│   └── index.js            # Entry point for the React application
├── package.json            # npm configuration file
└── README.md               # Project documentation
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone https://github.com/yourusername/CornHacks2025.git
   cd banana-ide-frontend
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm start
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to access the Banana IDE.

## Usage

- Use the **Code Editor** to write your banana language code using banana-related emojis.
- Click the **Run Button** to execute your code.
- View the output in the **Console** section below the editor.

## About the Banana Language

The banana language is a fun and simple programming language designed for educational purposes. It utilizes emojis to represent various programming constructs, making it accessible for beginners and engaging for users of all ages.
